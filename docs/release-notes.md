Update your installed Decky plugins directly from their developers, without downloading each ZIP by hand.

### Install once

Enable **Developer Mode** in **Decky → Settings → General**, then open **Developer** and install from this URL:

```text
https://github.com/nukeador/decky-direct-updater/releases/latest/download/Decky-Direct-Updater.zip
```

Or download **Decky-Direct-Updater.zip** below and use **Install Plugin from ZIP**.

### v0.1.4

- **Find Plugins:** search by name, owner/repository or GitHub URL from the search icon beside Refresh.
- See repository descriptions, stars and fork labels in compact results. Descriptions reuse the search response without additional requests.
- Open a result to check compatible Decky releases, then install through Decky's native confirmation.
- Installed plugins are recognized to avoid duplicates. Successful installations are tracked for future updates.
- Search results are cached; Show more reveals five at a time. Compatibility checks run only for the selected repository.
